# Cours 23 — Fondamentaux du développement web

**Classe :** E2
**Semaine de cours :** 16–20 août 2027
**Semaine PPE associée :** semaine suivante
**Référence CFC :** à confirmer avec le plan de formation (domaine : développement d'applications web)

## Contexte pédagogique

Durant la semaine de formation, les étudiants suivent le cours *Fondamentaux du développement web*.
Durant la semaine **PPE** qui suit, chaque étudiant (ou binôme, selon la consigne du formateur) choisit **un des 5 projets ci-dessous** et le réalise en autonomie, avec le support du formateur référent.

Les cinq projets forment une progression continue autour d'un même cas fil rouge, le site d'une association : chaque projet reprend le résultat du précédent. Le projet 5 réinvestit directement les acquis du cours 19 sur l'intégration continue.

## Modalités communes

- **Durée :** 1 semaine (PPE)
- **Rendu :** dépôt du rapport (Markdown ou PDF) + preuves (captures d'écran, code, fichiers de configuration) dans un sous-dossier `rendu-<nom-etudiant>/` créé par l'étudiant à côté de la fiche projet choisie.
- **Encadrement :** Morrad (formateur référent)
- **Notation :** voir le barème détaillé dans chaque fiche de projet (échelle suisse, note sur 6, seuil de réussite 4.0/6).
